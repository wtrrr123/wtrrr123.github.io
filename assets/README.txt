# assets 图片资源文件夹（说明）

本文件夹用于存放个人主页需要的图片资源，例如：

- `wooper-default.png` —— 自定义光标：普通（蓝）乌波，默认悬浮态（见 CSS 第 17 / 17.1 节）
- `wooper-active.png` —— 自定义光标：异色（粉）乌波，鼠标按下态（见 CSS 第 17 / 17.1 节）
- `sticker-*.gif` —— V4 吉伊卡哇角色动图共 10 张，全站主题化装饰（见 CSS 第 20 节）
- `hachiware-hero.png` —— 小八装饰图：Hero 首屏右下角（见 CSS 第 15 节 A 段）
- `hachiware-badge.png` —— 小八装饰图：项目卡片右上角标（见 CSS 第 15 节 B 段）
- `hachiware-contact.png` —— 小八装饰图：联系我模块侧边（见 CSS 第 15 节 C 段）
- `hachiware.png` —— 小八装饰图：**备用素材**（当前未被 CSS 引用，可随时换上去）
- `avatar.jpg` —— 个人头像（V1 暂用文字字母徽标占位，无需图片）
- `project-1.png` —— 项目截图（后续 V2/V3 可放真实截图）
- 其它封面 / 图标等

所有代码中引用图片时，请使用「相对路径」，例如 `assets/avatar.jpg`。

### 如果以后想换图

- 保持同名覆盖即可（如 `assets/hachiware-badge.png`），CSS 不用改；正方形图可直接沿用。
- 图片尺寸不同也不会错位 —— 角标取景用的是百分比，
  会随容器大小自动按比例缩放（移动端 24px 时同样成立）。
- 想让角标也显示全身：把 CSS 第 15 节 B 段里的
  `background-size: 180%` 与 `background-position: 59% 73%` 改回 `contain` 与 `center`。
- 想给三处换成别的图：把 CSS 第 15 节 A / B / C 三段里的 `url(...)` 文件名分别改掉即可。
  备用图 `hachiware.png` 就是这么用的。
- 建议使用透明背景 PNG（带白底 / 棋盘格的图会显示成方块）。
  当前主素材为 282×282，在 120px 处长边约 2.3 倍：普通屏与 2K 屏都清晰，
  追求更锐利可换 ≥ 480×480 的同款图。
- 装饰统一 `pointer-events: none`，不会挡住任何按钮、链接与歌单 iframe。

### 素材处理说明（重要）

从素材站（爱给网）免费下载的 PNG 是**带棋盘格浮水印的预览版** ——
文件虽然是 PNG，但 alpha 全为 255（不透明），直接使用会让装饰
显示成一个灰白格子的方块，而不是角色。

本目录里的四张图都已做过去背处理：从画面边界向内 flood fill
（容差 14、亮度 ≥ 215）删除连通的灰白区；角色内部的白色（脸 / 身体）
因为被黑色轮廓包住，不会被删掉，所以处理后的图是真正透明的。

以后从同一来源换图时，记得也做一次去背，或改用本身自带透明通道的素材。

### 素材处理说明（GIF 与 PNG 不同）

V4 的 GIF **本身自带透明通道**（下载下来就是透明的），
所以不需要像小八 PNG 那样做去背处理。处理只做了「降采样 + 调色板量化」：

- 每张先缩到展示尺寸的 2 倍（如 120px 展示 → 150px 宽素材），兼顾清晰与体积；
- 调色板量化时用 `reserve_transparent=1` 保留透明索引、`dither=none`（扁平卡通色最干净）；
- 每张都逐像素统计过 alpha 透明像素比例，压缩前后一致 —— 透明通道未被破坏。

如果以后自己换 GIF：建议同样输出「展示尺寸 ×2」的透明 GIF。
另注意 GIF 没有半透明，边缘抗锯齿的半透明像素会被量化成实心 ——
所以素材最好本身就是硬边缘的卡通图（本目录这批即是）。

### 动画是怎么显示出来的（重要）

这两张图是**动图**（APNG 格式），但 **CSS 的 `cursor` 属性不支持动图** ——
把 APNG / GIF 写进 `cursor` 里，浏览器只会画第一帧，看起来就是一张静态图。

因此本项目的光标分成两层：

| 层次 | 作用 | 位置 |
| --- | --- | --- |
| 静态回退 | 脚本未运行时使用；只显示动图的第一帧 | CSS 第 17 节的 `cursor` 规则 |
| 动画显示 | 跟随鼠标的元素，真正播放 79 帧动画 | CSS 第 17.1 节 + `index.html` 的 `.cursor-follow` + `js/main.js` 功能 5 |

启用动画显示时会隐藏系统光标（`cursor: none`），跟随图层自身不拦截点击。
以下情况会自动退回静态光标，不会出现「没有光标」的尴尬情况：

- 触屏 / 无精确指针的设备（`hover: none` 或 `pointer: coarse`）；
- 系统开启了「减少动态效果」（`prefers-reduced-motion: reduce`）；
- `js/main.js` 未加载或被浏览器阻止执行。

### 如果以后想换图

- 保持同名覆盖即可，CSS 与 JS 都不用改。
- 用动图（APNG / GIF）或静态 PNG 都可以；静态图也能正常显示，只是不会动。
- 图片尺寸与原图不同时，要同步修改两处热点偏移，否则会「点不准」：
  - CSS 第 17 节与第 17.1 节里 `url(...)` 后面的两个数字；
  - `js/main.js` 功能 5 里的 `CURSOR_HOTSPOT_X` 与 `CURSOR_HOTSPOT_Y`。
  当前热点为 `12 12`；若换成 40×40 的图，写 `20 20`（图片中心）最自然。
- 请使用透明背景；带白色底的图片会显示成一个方块。
